# pipe-test-2

## Сума

`scripts/sum.sh` виводить суму цілих чисел, переданих аргументами. Без аргументів виводить `0`.
Якщо хоч один аргумент не є цілим числом, скрипт пише повідомлення в stderr і завершується з кодом 1.

```sh
$ scripts/sum.sh 2 3 5
10
$ scripts/sum.sh
0
$ scripts/sum.sh 2 x
sum.sh: не число: 'x'    # код виходу 1
```

Тести: `bash tests/sum_test.sh`.

## Статистика

`scripts/stats.sh` виводить статистику цілих чисел, переданих аргументами: кількість, мінімум, максимум і середнє (з двома знаками після коми).
Без аргументів або з нечисловим значенням скрипт пише повідомлення в stderr і завершується з кодом 1.
Перевірка «це число» спільна з `scripts/sum.sh` і лежить у `scripts/lib/numbers.sh`.

```sh
$ scripts/stats.sh 3 1 2
count 3
min 1
max 3
avg 2.00
$ scripts/stats.sh
stats.sh: немає чисел    # код виходу 1
$ scripts/stats.sh 2 x
stats.sh: не число: 'x'    # код виходу 1
```

Тести: `bash tests/stats_test.sh`.
